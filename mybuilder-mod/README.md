# MyBuilder Mod для Minecraft 1.21.1 (Forge)

Мод для строительства по JSON-схемам с удобным интерфейсом. Работает только на клиенте - можно заходить на любые сервера без мода!

## Функции
- Загрузка JSON-файлов с постройками из папки `mybuilder_builds/`
- Удобное меню с выбором постройки (клавиша **B**)
- Просмотр статистики блоков
- Строительство по слоям или по типу блоков
- Поддержка построек до 500×500×500 блоков

## Установка

### 1. Требования
- Minecraft 1.21.1
- Forge 52.0.11 или выше
- Java 21

### 2. Сборка мода
```bash
cd /workspace/mybuilder-mod
gradle build
```
*(На Windows: `gradlew.bat build`)*

### 3. Установка в Minecraft
1. Найдите файл `.jar` в папке `build/libs/` (например, `mybuilder-mod-1.0.0.jar`)
2. Скопируйте его в папку `%appdata%\.minecraft\mods`
   - Нажмите `Win+R`, введите `%appdata%`, перейдите в `.minecraft\mods`
   - Если папки `mods` нет — создайте её
3. Запустите Minecraft с профилем Forge 1.21.1

## Использование

### Создание постройки
1. Создайте папку `mybuilder_builds` в корне Minecraft (`%appdata%\.minecraft\`)
2. Положите туда JSON-файл с постройкой (см. пример ниже)
3. В игре нажмите **B** для открытия меню
4. Выберите постройку и нажмите "Строить"

### Пример JSON-файла
Создайте файл `house.json` в папке `mybuilder_builds/`:

```json
{
  "structure": {
    "name": "Мой дом",
    "author": "Я",
    "blocks": [
      {"pos": [0, 0, 0], "state": "minecraft:stone"},
      {"pos": [1, 0, 0], "state": "minecraft:stone"},
      {"pos": [0, 1, 0], "state": "minecraft:oak_log"}
    ]
  }
}
```

### Формат JSON
- `pos`: [x, y, z] — координаты блока
- `state`: полное имя блока (например, `minecraft:stone`)
- Постройка центрируется относительно игрока при строительстве

## Генерация построек через ИИ

Используйте этот промпт для генерации построек:

```
Ты — профессиональный генератор структур для мода Minecraft "MyBuilder" (версия 1.21.1).  
Твоя задача: сгенерировать ТОЛЬКО валидный JSON-код для постройки на основе моего описания.

СТРОГИЕ ПРАВИЛА ГЕНЕРАЦИИ:
1. ФОРМАТ: Ответ должен содержать ТОЛЬКО код JSON в блоке кода. Никаких объяснений до или после.
2. СТРУКТУРА:
   - Корневой объект должен иметь ключ "structure".
   - Внутри "structure" должен быть массив "blocks".
   - Каждый элемент массива — это объект с полями: "pos" [x, y, z], "state" (строка названия блока).
3. КООРДИНАТЫ:
   - Постройка должна начинаться с 0,0,0 или быть центрирована.
   - Ось Y направлена вверх.
   - Максимальный размер: 500x500x500 блоков.
4. БЛОКИ:
   - Используй ТОЛЬКО полные имена блоков Minecraft 1.21.1 (например: "minecraft:stone", "minecraft:oak_planks").
   - Для воздуха блок указывать НЕ НУЖНО.
5. ЛОГИКА ПОСТРОЙКИ:
   - Постройка должна быть цельной, узнаваемой и архитектурно верной.
   - Избегай случайного шума блоков.

ШАБЛОН JSON:
{
  "structure": {
    "name": "Название постройки",
    "author": "AI_Architect",
    "blocks": [
      {"pos": [0, 0, 0], "state": "minecraft:stone"},
      {"pos": [0, 1, 0], "state": "minecraft:oak_log"}
    ]
  }
}

МОЙ ЗАПРОС НА ПОСТРОЙКУ: 
[Вставь сюда описание, например: "Двухэтажный средневековый дом 12x14 с черепичной крышей"]
```

## Управление в моде
- **B** — открыть главное меню
- В меню строительства:
  - "< Пред. слой" / "След. слой >" — навигация по слоям
  - "Режим" — переключение между построением по слоям и по типам блоков
  - "ПОСТРОИТЬ СЛОЙ" — построить текущий слой
  - "ПОСТРОИТЬ ВСЁ" — построить всю постройку (требуется креатив)

## Примечания
- Мод работает только в креативном режиме или на серверах, где у вас есть права на строительство
- Для больших построек используйте режим построения по слоям
- Все файлы JSON должны быть в кодировке UTF-8

## Поддержка
При возникновении проблем проверьте логи Minecraft в файле `logs/latest.log`.
