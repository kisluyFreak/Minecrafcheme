# MyBuilder - Мод для строительства из JSON

Мод для Minecraft 1.21.1 (Forge), который позволяет загружать постройки из JSON-файлов, сгенерированных ИИ, и строить их в игре.

## Возможности

✅ **Загрузка JSON** - читает файлы из папки `mybuilder_builds/`
✅ **Поддержка больших построек** - до 500x500x500 блоков
✅ **Удобный UI** - 5 экранов интерфейса
✅ **Статистика блоков** - подсчёт количества каждого типа блоков
✅ **Строительство по слоям** - стройте этаж за этажом
✅ **Строительство по типам блоков** - фильтруйте по типу блока
✅ **Призрачные блоки** - предварительный просмотр
✅ **Клиентский мод** - работает на серверах без установки!

## Установка

1. Установите **Minecraft 1.21.1** с **Forge 52.0.11+**
2. Соберите мод: `./gradlew build`
3. Скопируйте `build/libs/mybuilder-mod-1.0.0.jar` в папку `mods`
4. Запустите игру

## Как использовать

### 1. Создайте постройку через ИИ
Попросите ИИ (например, меня) создать JSON-файл с постройкой.

### 2. Сохраните JSON
Положите файл в папку `mybuilder_builds/` рядом с игрой.

### 3. Откройте меню
В игре нажмите клавишу **B** для открытия меню.

### 4. Выберите постройку
- Выберите файл из списка
- Посмотрите статистику блоков
- Начните строительство

### 5. Стройте
- Переключайтесь между слоями (Y)
- Или фильтруйте по типу блока
- Используйте призрачные блоки для разметки

## Формат JSON

Мод поддерживает **два формата** JSON:

### Формат 1 (старый, простой):
```json
{
  "name": "Мой дом",
  "dimensions": {
    "width": 10,
    "height": 5,
    "depth": 8
  },
  "blocks": [
    {"id": "minecraft:stone", "x": 0, "y": 0, "z": 0},
    {"id": "minecraft:oak_planks", "x": 1, "y": 0, "z": 0}
  ]
}
```

### Формат 2 (новый, рекомендуемый для ИИ):
```json
{
  "structure": {
    "name": "Мой дом",
    "author": "AI_Architect",
    "blocks": [
      {"pos": [0, 0, 0], "state": "minecraft:stone"},
      {"pos": [1, 0, 0], "state": "minecraft:oak_planks"}
    ]
  }
}
```

**Важно:** Мод автоматически распознаёт оба формата!

## Промпт для создания постройки ИИ

Скопируйте этот промпт и отправьте ИИ для генерации JSON:

---

**ПРОМПТ ДЛЯ ИИ:**

Ты — профессиональный генератор структур для мода Minecraft "MyBuilder" (версия 1.21.1).  
Твоя задача: сгенерировать ТОЛЬКО валидный JSON-код для постройки на основе моего описания.

**СТРОГИЕ ПРАВИЛА ГЕНЕРАЦИИ:**

1. **ФОРМАТ ОТВЕТА:** 
   - Ответ должен содержать ТОЛЬКО код JSON в блоке кода.
   - Никаких объяснений, комментариев или текста до или после JSON.

2. **СТРУКТУРА JSON (используй новый формат):**
```json
{
  "structure": {
    "name": "Название постройки",
    "author": "AI_Architect",
    "description": "Краткое описание",
    "blocks": [
      {"pos": [x, y, z], "state": "minecraft:block_name"},
      {"pos": [x+1, y, z], "state": "minecraft:block_name"}
    ]
  }
}
```

3. **КООРДИНАТЫ:**
   - Постройка должна начинаться с координат 0,0,0 или быть центрирована относительно 0,0,0
   - Ось Y направлена вверх (Y=0 — первый этаж)
   - Максимальный размер: 100x100x100 блоков (для больших построек)
   - Избегай отрицательных координат, если это не критично для симметрии

4. **БЛОКИ:**
   - Используй ТОЛЬКО полные имена блоков Minecraft 1.21.1 в формате `minecraft:block_name`
   - Запрещено выдумывать несуществующие блоки
   - Если не уверен в блоке — используй `minecraft:stone` или `minecraft:oak_planks`
   - Для воздуха блок указывать НЕ НУЖНО (просто пропускай эти координаты)
   - Примеры валидных ID: `minecraft:stone`, `minecraft:oak_log`, `minecraft:glass`, `minecraft:cobblestone`, `minecraft:oak_stairs`

5. **ЛОГИКА ПОСТРОЙКИ:**
   - Постройка должна быть цельной, узнаваемой и архитектурно верной
   - Соблюдай логику строительства: фундамент → стены → крыша
   - Добавляй окна, двери, декоративные элементы
   - Избегай случайного шума блоков и хаотичного размещения
   - Для крыши используй лестницы (`minecraft:oak_stairs`) или плиты
   - Для окон используй `minecraft:glass` или `minecraft:glass_pane`

6. **ПРОВЕРКА:**
   - Убедись, что каждый блок имеет поля `pos` (массив из 3 чисел) и `state` (строка)
   - Убедись, что все координаты целые числа
   - Убедись, что постройка имеет логическую структуру

**МОЙ ЗАПРОС НА ПОСТРОЙКУ:**  
[ВСТАВЬ СЮДА СВОЁ ОПИСАНИЕ]

Пример запроса: "Двухэтажный средневековый дом 12x14x8 с каменным фундаментом, деревянными стенами, черепичной крышей из ступенек, большими окнами и дверью спереди"

## Управление

| Клавиша | Действие |
|---------|----------|
| B | Открыть меню мода |
| ЛКМ+Shift | Поставить призрачный блок |
| ПКМ+Shift | Установить реальный блок |
| Колесо мыши | Прокрутка списков |
